# 肠道菌群 → 膳食营养 孟德尔随机化权重

`diet_mr_weights.json` 是消费者版“膳食营养评分”唯一读取的权重文件，由
`scripts/import_diet_mr.py` 从产品提供的两张表生成：

- `菌_膳食营养_评分.xlsx`：肠道菌群性状（菌种/菌属/科…丰度或有无、功能通路、α多样性，
  1,572 个暴露）对 UK Biobank 24 小时膳食回顾 22 种营养素估算值（字段 100002–100025）的
  两样本 MR（IVW）结果，34,584 行；
- `膳食营养表型清单.xlsx`：UK Biobank 字段 ID、英文名和中文名。

源表的 sha256 和行数记录在 JSON 的 `source` 字段，源表本身不入库。

## 纳入规则（与疾病 MR 相同）

- IVW P < 0.05；
- 只用**丰度**类性状：菌种丰度、菌属丰度、α多样性。
- 每条保留原始性状名、暴露 GWAS 编号、SNP 数、β、P、−lgP。

结果：22 种营养素、669 条性状，每种 19–41 条。每种营养素检验了约 400 条丰度性状，
P<0.05 偶然预期约 20 条；BH 校正（FDR<0.05）后只剩 11 条。评分用 −lgP 加权，
但整体证据偏弱，报告中已说明。

## 方向与分组

每种营养素的显示分组和在综合分中的方向写在 `scripts/import_diet_mr.py` 的
`NUTRIENT_ROLES`，导入时写进权重文件：

| 方向 | 营养素 |
|---|---|
| 鼓励（encourage） | 膳食纤维、多不饱和脂肪、维生素 B6/B12/C/D/E、叶酸、胡萝卜素、铁、钾、镁、钙 |
| 限制（limit） | 饱和脂肪、总糖、酒精 |
| 中性（neutral，只展示不计入） | 能量、蛋白质、脂肪、碳水化合物、淀粉、视黄醇 |

## 评分

    每种营养素倾向分 = Σ β × (−lgP) × z
    综合评分（0–100）= mean(鼓励类百分位, 100 − 限制类百分位)

z 与疾病风险评分相同（见 `src/wgs_agent/reporting/disease_risk.py`）；百分位相对 cMD
健康成人。倾向分表示“与该营养素摄入较多相关的菌群特征有多明显”，不是实际摄入量。

## 更新

```bash
.venv/bin/python scripts/import_diet_mr.py --mr 菌_膳食营养_评分.xlsx --nutrients 膳食营养表型清单.xlsx
```

输出是确定性的。服务器上的参考包目录名带本文件哈希，提交新文件并
`bash deploy/restart.sh` 后会在后台自动重建（`prepare_cmd_data.py` 第7步），旧包保留不动。
