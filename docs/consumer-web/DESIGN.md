# 消费者版网页报告设计规范

本文是 `feat/consumer-web-report` 的实现规范整理。专业版 PDF、Markdown 与结构化 JSON 保持不变；消费者版是独立视图模型。

## 1. 读者与语气

- 读者是没有生物医学背景的成年人，主要在手机上阅读，一次读 3–5 分钟。
- 统一称呼“您”。短句，先结论后含义。
- 不诊断、不写患病概率、不写因果关系；不推荐药品、益生菌、补充剂或产品。
- “偏离常见范围”写“较少见”，不写“异常”。“检出基因”不等于“正在致病”。

## 2. 文案边界

正文不出现：未提供、未启用、暂无法判断、已记录、本节、如图所示、综上所述、值得注意的是、【、】。

正文不出现技术标识：`g__`、`s__`、`k__`、P5/P95、经验百分位、bootstrap、MetaPhlAn、HUMAnN、cMD、VFDB、ResFinder、RPKM、reads、PWY- 开头的通路编号、MV 编号、NC_ 参考编号、科学计数法。它们只允许出现在“了解更多 / 方法与数据”和 CSV 明细中。

## 3. 数字规则

- 百分比：≥1 保留 1 位小数；0.1–1 保留 2 位小数；0.01–0.1 保留 2 位有效数字；<0.01 写 `<0.01%`。
- 人数使用千分位，例如 3,537。
- 百分位不直接显示，改写为“高于/低于约 N% 的参考人群”或“高于/低于 99% 以上的参考人群”。
- 所有业务数值由 Python `format.py` 生成 `display`；前端不得用 `toFixed` 格式化业务数值。
- 千分位整数计数是产品明确要求的例外，不按有效数字上限截断。

## 4. 分档与语义颜色

| 百分位 | 档位 |
|---|---|
| < P5 | 明显偏低 |
| P5–P25 | 略低 |
| P25–P75 | 常见 |
| P75–P95 | 略高 |
| > P95 | 明显偏高 |

置信区间跨越档位边界时降一档，不使用“明显”。

| 语义 | 前景 | 背景 |
|---|---|---|
| good | `#2E7150` | `#E4F1E8` |
| neutral | `#45606A` | `#E8EEF0` |
| watch | `#9A5410` | `#FBEBD8` |
| consult | `#A63D2A` | `#F8E1DB` |

颜色从不单独表意，旁边必须有文字标签。consult 只用于“请就医”提示框。

## 5. 信息架构

固定顺序：总览 → 菌群组成 → 多样性 → 重点菌 → 致病基因 → 耐药基因 → 细菌以外 → 食物与营养 → 代谢产物 → 更多线索 → 行动建议 → 了解更多。

每个小节：小节标题 → 内容块 → 1–2 句小结 → 一幅与本小节最相关的知识子图。没有数据的块不渲染；整节为空时整节不出现并登记 `omissions`。

## 6. 术语与子图

- 术语解释只来自 approved 术语库；pending 和 rejected 不进入正文。
- 术语用虚下划线标出；手机点击为底部抽屉，桌面为气泡；Esc 关闭；焦点回到原处。
- 知识子图只保留含 seeds 的连通分量，最多 2 个；正文最多 8 个节点、6 条边；清洗后不足 2 条边不出图。
- 节点标签只用中文；未审核边画虚线；图例写“虚线：尚待人工核对的研究结论”，正文不写“待审核”。
- 全报告第一次出现子图时显示一次读图说明。

## 7. 视觉规范

- 作用域：`.cr-root`，样式文件 `apps/workspace-web/app/consumer/consumer-report.css`。
- 背景 `#F6F4EF`，卡片 `#FFFFFF`，正文 `#1C2629`，次要文字 `#5A6468`，分隔线 `#E6E2D9`，品牌 `#145C58`，品牌浅色 `#E3EFEC`。
- 字体只用系统字体栈：`"PingFang SC","Noto Sans SC","Microsoft YaHei",system-ui,sans-serif`；数字使用 `font-variant-numeric: tabular-nums`；不引用外部字体 CDN。
- 正文 16px，行高 1.7；h1 28px；部分标题 22px；小节标题 18px；辅助文字 13px，最小 12px。
- 卡片圆角 16px，内边距 18–20px；卡片间距 12px；部分间距 48px。
- 手机 <768px：单列、左右边距 20px、吸顶横向目录。≥1024px：左侧 220px 吸顶目录，正文列最大 720px 居中。
- 375px 下无横向滚动；宽表格放在 `overflow-x:auto` 容器中。
- 可点击元素使用 `button`/`a`，有可见焦点样式；点击区域尽量 ≥44px。

## 8. 打印

“下载 PDF”调用 `window.print()`。打印样式使用 A4、隐藏目录和按钮、卡片不跨页断开、子图改为文字列表、“了解更多”全部展开。消费者版 PDF 与专业版 PDF 分开下载。

## 9. 数据结构

契约 `consumer-report/1` 由三处定义并互相对应：

- `src/wgs_agent/consumer_web/schema.py`（pydantic v2）；
- `docs/consumer-web/consumer-report.schema.json`（导出的 JSON Schema）；
- `apps/workspace-web/lib/consumer-report.ts`（TypeScript 类型）。

所有数字已经由 Python 格式化；前端只渲染 `display`。
