## 1. 总体设计

```
菌群 GWAS（暴露，需提供）─┐
UKB NMR 代谢物 GWAS（结局）┴─► 两样本 MR ─► 代谢物 MR 权重 ─┐
                                                           │
样本 MetaPhlAn3 物种谱 ─┬─► [A] 血液代谢倾向评分（NMR 168 项 → 归并为 8–10 个维度）
                        ├─► [B] 营养摄入 / 其余生化（图1、图2，需另找 GWAS，二期）
                        └─► [C] 菌种功能数据库 × 丰度 ─────► 食物与营养总分 + 食物建议
HUMAnN 通路谱 ──────────────► 交叉校验 [C]（已有 vitamin/substrate map）
```

- **[A] 复用疾病风险评估引擎**：`score = Σ β × (−lgP) × z`，与 `src/wgs_agent/reporting/disease_risk.py`
  相同的命名对齐（`MPA_TO_GTDB` / `MR_ALIASES`）、z 截断和证据权重覆盖率。连续性状没有患病人群，只输出健康人群百分位。
- **[C] 新建菌种功能数据库**：物种为主键，菌株为子记录；样本得分 = Σ(物种相对丰度 × 功能值)，换算为 cMD
  健康人群百分位。报告中标注为“按物种推断”，与 HUMAnN 实测区分。

## 2. 菌群 → 代谢物 MR（新增工作，原方案没有）

**输入**

- 暴露：菌群 GWAS。疾病 MR 的性状是 GTDB 命名、包含菌种/菌属丰度与有无、功能通路和 α 多样性，看起来与
  FINRISK 2002 菌群 GWAS（Qin 等 2022 Nat Genet）一致。**需要产品确认来源并提供工具变量 SNP 集**；
  如能直接给出疾病 MR 用的 IV 表，可保证两套评分口径一致。
- 结局：lx 的 168 个 GCST 文件。

**数据量与做法**

- 单文件约 3.3 GB（已实测 GCST90449612），168 个约 560 GB，249 个约 830 GB。
- **不落盘全量文件**：逐个流式下载并解压，只保留工具变量 rsID（几千个）对应的行，结果只有 MB 级。
  按 EBI FTP 10–30 MB/s 估算，下载耗时约 5–15 小时，可断点续跑、按 md5 校验。
- 结局是 GRCh38，暴露 GWAS 可能是 GRCh37：以 rsID 对齐，rsID 缺失的行按 GRCh38 坐标回补；做等位基因方向
  协调，回文 SNP 按 EAF 判定或剔除。

**方法与纳入规则**

- IVW 为主，同时算 MR-Egger、加权中位数、Steiger 方向检验、异质性（Cochran Q）；用 R `TwoSampleMR`
  或 Python 自实现（项目已有 numpy，流程较简单）。
- 进入评分：IVW P<0.05、只用丰度类性状（与疾病 MR 一致），建议额外要求敏感性分析方向一致、Steiger 通过。
- 输出 `knowledge_base/metabolite_mr/metabolite_mr_weights.json`，格式对齐 `disease_mr_weights.json`，
  记录暴露/结局 GWAS 版本、文件 md5、纳入规则，输出确定性。

**维度归并（消费者版）**

168 项高度相关，122 项脂蛋白亚类直接相加会重复计数。建议消费者版归并为约 8–10 个维度，每维选 2–4 个
代表性状，专业版保留全部 168 项明细：

| 维度 | 代表性状 |
|---|---|
| 血脂谱 | 总胆固醇、LDL-C（临床）、HDL-C、总甘油三酯、非 HDL-C、残余胆固醇 |
| 载脂蛋白 | ApoA1、ApoB |
| 脂肪酸质量 | ω-3、DHA、ω-6、饱和脂肪酸、不饱和度 |
| 血糖与能量 | 葡萄糖、乳酸、丙酮酸、柠檬酸 |
| 支链氨基酸 | 亮/异亮/缬氨酸总量 |
| 酮体 | 3-羟基丁酸、乙酰乙酸、丙酮 |
| 短链脂肪酸 | 乙酸盐（与肠菌发酵直接相关） |
| 炎症 | GlycA（乙酰化糖蛋白） |
| 肾功能/蛋白 | 肌酐、白蛋白 |

生物学上“菌群 → 血液代谢物”比“菌群 → 膳食摄入”方向更合理（乙酸、乳酸、支链氨基酸、GlycA 都有肠菌机制
文献），**所以这部分比原方案的营养摄入 MR 更可信，建议作为一期主线**。

## 3. 图1、图2（二期）

- 图2 血液生化中，葡萄糖、肌酐、白蛋白、总胆固醇、LDL、HDL、甘油三酯、ApoA、ApoB 已被 NMR 覆盖，优先用
  NMR；剩下与饮食相关的 HbA1c、CRP、尿酸、维生素 D、ALT、GGT、钙、磷，可从 Pan-UKBB 或 Neale Lab
  的 UKB GWAS 补充。性激素、类风湿因子、IGF-1 等不进总分。
- 图1 的 22 项膳食营养同样可从 Pan-UKBB 或 Neale Lab 获取 GWAS。但“菌群 → 膳食摄入”的 MR 方向与生物学
  相反，且菌群工具变量弱。建议用文献驱动的“饮食质量菌群指数”作为主分（如 Asnicar 2021 Nat Med 的
  15 个有利、15 个不利物种），MR 只作辅助维度。

## 4. 菌种功能数据库（图3字段，已去掉黏附）

粒度：物种级为主（约 500 个 cMD 健康人群常见种 + 全部益生菌名录种）。菌株级只记录商业菌株和菌株特异文献。
每个字段存 `value / method（genome|database|literature）/ source / PMID / 版本`。

| 组 | 字段 | 数据来源 | 可行性 |
|---|---|---|---|
| 体内功能 | 免疫调节（促炎/抗炎） | 文献整理（LitKG + PubMed，LLM 抽取 + 人工复核）；基因组线索（LPS 脂质A、鞭毛蛋白） | 中低：强菌株特异 |
| | 抗增殖 | 仅文献（多为细胞实验） | 低 |
| | 抑菌（细菌素） | BAGEL4 / antiSMASH RiPP | 高 |
| | 抗氧化 | 基因组（katE、SOD、谷胱甘肽合成、NADH 氧化酶）+ 文献 | 中 |
| | 肠屏障保护 | 文献为主；间接由丁酸/吲哚类推断 | 中低 |
| 代谢 | 产 SCFA（丁/乙/丙酸）、产乳酸（L/D） | 丁酸四条通路标志基因、ack/pta、琥珀酸/丙烯酸/丙二醇通路、ldhL/ldhD；可用 AGORA2、UHGG 预注释 | 高 |
| | BSH / 胆汁酸转化 | bsh（K01442）、bai 操纵子 | 高 |
| | 色氨酸代谢 | tnaA、fldH 等 | 高 |
| | 维生素（B/K） | Magnúsdóttir 2015 + KEGG 模块（men → K2） | 高 |
| | EPS 胞外多糖 | eps/cps 基因簇 | 中：能判有无，难判功能 |
| | 产气特性 | [FeFe]-氢化酶、mcrA、dsrAB/半胱氨酸脱巯酶 | 中高 |
| 安全性 | ARGs | ResFinder（项目已有）/ CARD RGI，区分固有与获得性 | 高 |
| | VFs | VFDB core | 高 |
| | PGs | PathoFact 等；**需先给定义** | 中 |
| | PPRS 折算 | **公式未定义** | 待定 |
| | biosafety_level | BacDive / DSMZ 风险等级（TRBA 466）、ATCC | 高 |
| | 致病性记载 | BacDive、EFSA QPS、BV-BRC、文献 | 高 |
| 证据 | 文献 N、PMID | PubMed E-utilities（复用 `pubmed_pipeline.py`） | 高 |
| | 商业益生菌株 | 卫健委食品/婴幼儿食品菌种名单、EFSA QPS、FDA GRAS | 种级高；株级中 |
| | 致病菌 | 由 biosafety_level + 致病性记载派生 | 高 |
| | 文献益生证据 | 文献整理 | 中 |
| | 证据级别 | A 人体 RCT / B 人体观察 / C 动物 / D 体外 / E 仅基因组预测 | 高 |
| 背景 | 氧耐受、革兰 | BacDive | 高 |
| | 门/属/种 | NCBI + GTDB | 高 |

代谢、安全性、证据、背景约 80% 字段可自动化；体内功能主要靠文献，作为持续补充项，不阻塞上线。
功能库的“产 SCFA”可与 MR 的乙酸维度互相印证。

## 5. 可行性评估

| 维度 | 判断 | 说明 |
|---|---|---|
| 工程 | **高** | 评分引擎、cMD 参考包、命名对齐、导入脚本、消费者报告契约可复用 |
| 代谢物 MR 数据 | **高（结局）/ 待定（暴露）** | 结局 GWAS 公开、格式规范、n≈41 万；缺菌群暴露 GWAS 与 IV 集 |
| 代谢物 MR 计算 | **中高** | 约 560 GB 流式下载，十几小时；MR 本身计算量小 |
| 功能库 | **中高** | 公开库 + 预注释基因组覆盖大部分字段；体内功能需人工 |
| 科学解释 | **中** | 代谢物方向合理；膳食摄入方向存疑；菌群 IV 弱，单个性状效应小 |
| 验证 | **中** | cMD 部分研究有血脂、HbA1c、肌酐等临床字段，可做方向一致性检验（需在服务器确认） |

主要风险：

1. **暴露 GWAS 未定**：没有菌群 IV 集，MR 无法开始，这是一期最大阻塞点。
2. **工具变量弱**：菌群 IV 多集中于 LCT、ABO、FUT2 等少数位点，多性状共用 IV，结果可能由少数位点驱动；
   需要做留一法和多效性检查，消费者版只写“菌群特征提示的倾向”。
3. **医疗表述合规**：血液代谢只能写“菌群相关代谢倾向”，不得暗示指标异常或替代体检。
4. **物种推断 ≠ 实测**：功能库得分需与 HUMAnN 交叉校验；样本只到种，菌株级证据只能“同种参考”。
5. **未定义口径**：PPRS、PGs；Sheet3（细胞类型表）用途。
